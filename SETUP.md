# Руководство по настройке и развёртыванию LingoTwice (SETUP.md)

Документ описывает архитектуру, внешние интеграции, квоты, стоимость эксплуатации и пошаговую настройку приложения **LingoTwice** — многоязычного браузера параллельного чтения и изучения иностранных языков.

---

## 1. Выбранные сервисы и архитектура

1. **Фронтенд**: React 19, TypeScript, Tailwind CSS, Lucide Icons.
   - Чистый типографический интерфейс (без визуального шума), поддержка тем (Светлая, Тёмная, Сепия), масштабирование шрифта (14–26 px), межстрочный интервал.
   - Двунаправленная синхронная прокрутка с защитой от циклических событий и поабзацным выравниванием.
   - 4 режима чтения:
     - **Mode A (Параллельный)**: Полная видимость обоих языков.
     - **Mode B (С подсказками)**: Текст перевода размыт до наведения/клика.
     - **Mode C (Погружение)**: Перевод полностью скрыт до явного раскрытия пользователем.
     - **Mode D (Проверка знаний / Recall)**: Интерактивный опрос на понимание и закрепление контекста.
     - **Mode E (Интервальное повторение)**: Флэш-карточки по проверенному алгоритму SuperMemo SM-2 с корзинами Лейтнера (1–5).
2. **Бэкенд**: Express.js на Node.js (интегрирован с Vite-мидлварами в dev-режиме на порту 3000).
   - Эндпоинты `/api/translate`, `/api/dictionary/lookup`, `/api/comprehension/generate`, `/api/import-url`, `/api/subscription/status`, `/api/subscription/upgrade`.
3. **Искусственный интеллект и машинный перевод**: Google Gemini API (`@google/genai`, модель `gemini-3.8-flash`).
   - Используется для построчного перевода с сохранением структуры, глубокого грамматического разбора (род существительных, множественное число, формы глаголов, уровень CEFR) и генерации проверочных вопросов.
4. **Аудио**: Web Speech API браузера (нулевая задержка, без дополнительных затрат) с регулировкой скорости и автоматическим подбором диктора по языку.
5. **Безопасность**: Защита от SSRF (Server-Side Request Forgery) при импорте веб-статей по URL (блокировка 127.0.0.1, 10.x, 172.16-31.x, 192.168.x, 169.254.169.254 и метаданных).
6. **Кэширование**: Двухуровневое хэш-кэширование переводов на стороне сервера для экономии токенов и расходов.

## 2. Бесплатные тарифы и ограничения (Free Tiers & Limits)

| Сервис | Наличие Free Tier | Подтверждённые лимиты | Примечание |
|---|---|---|---|
| **Google Gemini API** (`gemini-3.8-flash`) | Да (Free Tier доступен в AI Studio) | До 15 RPM (запросов в минуту), 1 000 000 TPM, 1 500 запросов в день | Достаточно для активного персонального и группового чтения |
| **Web Speech API** | Полностью бесплатно | Не ограничено (выполняется на устройстве пользователя) | Зависит от установленных голосов ОС/браузера |

| **LocalStorage (гостевой режим)** | Полностью бесплатно | До 5–10 МБ на домен | Хранит тысячи слов и десятки книг без БД |

## 4. Настройка перевода и ИИ

1. Получите ключ Gemini API в Google AI Studio (`https://aistudio.google.com/`).
2. Добавьте его в панель **Secrets** AI Studio или в файл `.env` как `GEMINI_API_KEY`.
3. Сервер автоматически подхватит ключ при запуске. Если ключ не задан, активируется автономный демонстрационный режим с сохранением всей функциональности интерфейса.

---

## 5. Развёртывание в продакшене

Команда сборки:
```bash
npm run build
```
Запуск full-stack сервера:
```bash
npm start
```
`server.ts` автоматически определяет переменную `process.env.NODE_ENV === 'production'` и раздаёт статическую сборку из директории `dist/`, обрабатывая все API-маршруты.

## 6. Настройка монетизации и тарифов

В приложении реализовано разделение:
- **Free Tier**: 50 синхронных фрагментов в день, базовые функции библиотеки, интервальное повторение.
- **Premium Tier**: Безлимитный перевод, неограниченный URL-импорт, разбор грамматики уровня C2, отключение рекламных блоков.
- **Проверка статуса**: Проверяется серверным эндпоинтом `/api/subscription/status`. Для тестовой активации PRO доступен промокод `LINGOTWICE_PRO` прямо в интерфейсе.

## 7. Готовность к Google AdSense

В библиотеке и на свободных страницах выделен адаптивный, ненавязчивый рекламный слот:
- Не мешает чтению, навигации или выделению текста.
- Автоматически отключается для пользователей тарифа Премиум.
- До интеграции реального кода AdSense скрипты Google Ads не загружаются до согласия пользователя (GDPR-баннер согласия на cookie).
- Для подачи заявки в Google AdSense: привяжите собственный домен 2-го уровня, разместите `ads.txt` в папке `/public` и подайте сайт на верификацию в AdSense Console.
