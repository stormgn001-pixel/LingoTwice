# 📚 LingoTwice — Билингвальный браузер параллельного чтения

> **LingoTwice** — веб-платформа для комфортного параллельного чтения зарубежной литературы, статей и учебных материалов на языке оригинала с живым синхронным переводом, контекстным словарём и интервальным повторением (SRS).

![LingoTwice Banner](public/icon-512.png)

---

## ✨ Ключевые возможности

* 📖 **Синхронное параллельное чтение:** Отображение текста оригинала и перевода бок о бок с двусторонней синхронизацией прокрутки (Sync Scroll) и гибким разделением панелей (колонки / строки / смена сторон).
* ⚡ **Интеллектуальный ленивый перевод (Real-time Stream):** При добавлении больших книг и длинных статей перевод не перегружает модель, а подгружается в режиме реального времени на ~1000 символов вперёд от текущей позиции чтения с помощью модели **Gemini 3.1 Flash-Lite**.
* 🔍 **Контекстный ИИ-словарь:** Клик по любому слову открывает фонетическую транскрипцию (IPA), уровень CEFR (A1–C2), грамматический разбор (род, формы, части речи), контекстное значение в предложении и литературные примеры употребления.
* 🧠 **Интервальное повторение (SRS):** Изучайте сохранённые слова по алгоритму Лейтнера / SM-2 с карточками самопроверки и градацией сложности.
* 🎯 **3 режима чтения:**
  * **Параллельный (Parallel):** Текст оригинала и перевод видны одновременно.
  * **Погружение (Immersion):** Перевод скрыт карточкой-заглушкой и открывается по клику при возникновении трудностей.
  * **Проверка понимания (Recall):** ИИ генерирует интерактивные контрольные вопросы по прочитанному абзацу.
* 🔊 **Озвучивание текста (TTS):** Аудиовоспроизведение на любом из поддерживаемых языков с контролем темпа речи.
* 📥 **Универсальный импорт контента:** Вставка сырого текста с умной разбивкой на предложения, загрузка файлов (TXT, MD, PDF, EPUB) и защищённый импорт веб-статей по ссылке (с серверной защитой SSRF).
* 🎨 **3 темы оформления:** Светлая, классическая книжная Сепия и Тёмная тема.

## 🛠 Стек технологий

* **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, PDF.js
* **Бэкенд:** Node.js, Express, tsx
* **ИИ & API:** Google GenAI SDK (`@google/genai`) с моделями `gemini-3.1-flash-lite` и `gemini-3.8-flash`
* **Хранение данных:** LocalStorage (книги, словари, статистика, прогресс) и серверный in-memory кэш

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-username>/lingotwice.git
cd lingotwice
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Укажите ваш API-ключ Gemini:
```env
GEMINI_API_KEY="ваш_ключ_google_gemini_api"
```
*(Получить бесплатный API-ключ можно на [Google AI Studio](https://aistudio.google.com/app/apikey))*

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### 5. Сборка для продакшена
```bash
npm run build
npm start
```

## 📂 Структура проекта

```
lingotwice/
├── src/
│   ├── components/         # React-компоненты (Ридер, Библиотека, Словарь, Повторение, Импорт)
│   ├── constants/          # Поддерживаемые языки, библиотека образцов
│   ├── hooks/              # Хук синхронной прокрутки useSynchronizedScroll
│   ├── i18n/               # Многоязычные переводы интерфейса (10 языков)
│   ├── services/           # API клиент, синтез речи (TTS), SRS-алгоритм
│   ├── types/              # TypeScript-интерфейсы и типы данных
│   ├── App.tsx             # Корневой компонент и маршрутизация
│   └── main.tsx            # Точка входа React
├── server.ts               # Express сервер (API переводов, словаря, тестов, SSRF)
├── index.html              # HTML-шаблон и SEO мета-теги
├── metadata.json           # Метаданные AI Studio
├── package.json            # Зависимости и скрипты
└── vite.config.ts          # Конфигурация сборщика Vite
```
